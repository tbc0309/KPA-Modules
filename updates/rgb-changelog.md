## KPA RGB Control 1.0.0

- 升级保留用户配置；完善 LED 写入重试、单实例保护与退出关灯。
- 状态采样独立于动画速度，保持默认灯效节奏。
- Preserves user configuration on reinstall and handles failed LED writes, duplicate launches and shutdown safely.
- Samples device state independently of animation speed while retaining the default effects.
- Added Magisk module update detection.
- Provides performance-mode RGB effects, temperature alerts and screen-off power control.
